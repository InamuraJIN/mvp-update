## 🗺️ v2.0 Roadmap

### Lists (Favorites & Rankings)

- [ ] Integrated into the List screen
- [ ] Add Folders and Other Files sections to Favorites, in addition to Videos
- [ ] Clicking a folder opens the folder containing the files
- [ ] Rankings — add an "Other Files" tab, adjustable thumbnail size
- [ ] Add ranking calculation methods: Display Time, Playback Time, Display Count, and Play Count

### Layout & Display

- [ ] When displaying 3 videos, choose from 4 different layouts
- [ ] Drag divider lines to resize video cells (click intersection to reset to center)
- [ ] Change the position of highlight lines
- [ ] Default name label (Folder Name or File Name)
- [ ] Display next to the seek bar (Time or Frame Number)

### Playback & Controls

- [ ] Combine Fast Forward and Rewind under "Skip" in the Playback menu
- [ ] Combine Zoom and Pan controls under "Pan & Zoom" in the View menu
- [ ] When no video is selected, frame-by-frame and range selection shortcuts apply to all videos
- [ ] Playback & Repeat Synchronization: Off / Wait for longest / End with shortest
- [ ] Frame-by-frame navigation with Alt + Mouse Wheel
- [ ] Rename and move files even while they are playing

### New Features

- [ ] Compare two videos — Mix or Wipe mode with slider (Free: 10 min/day)
- [ ] Transform (Right-click): Rotate 90 degrees, flip horizontally/vertically, change aspect ratio
- [ ] Delayed Play (Right-click): Start another video at the current frame; repeats until stopped (Free: 10 min/day)
- [ ] Free Crop (Right-click > Crop): Crop to any shape using a single slider

### Capture

- [ ] Choose save method (Combined / Individual)
- [ ] Add options for capture parameters: Selection Frame, Zoom/Crop, Seek Bar, Name Label, Highlight Frame

### Shortcuts

- [ ] Customize keyboard shortcuts in Shortcuts (F1) — select action, click "Change", press key; Ctrl/Shift/Alt via buttons; warning on duplicate

### Settings & Languages

- [ ] Organize Settings tabs: rename "Data" to "Capture", move Cache Folder to "General", add "Controls" tab for cursor/mouse-over UI, close menus on mouse-out
- [ ] Languages: Download additional languages from update site (Settings > General > Language) — Japanese, Spanish, Simplified Chinese

### Support

- [ ] Help > Previous Session: Show last session info (actions, screen, videos)
- [ ] Attach video info to bug reports (format, codec, resolution — no filenames); preview before sending
