- [ ] Rankings: add an "Other Files" tab, adjustable thumbnail size
- [ ] Rankings: add calculation methods — Display Time, Playback Time, Display Count, Play Count
- [ ] Layout: when displaying 3 videos, choose from 4 different layouts
- [ ] Layout: drag divider lines to resize video cells (click intersection to reset to center)
- [ ] Layout: change the position of highlight lines
- [ ] Layout: default name label (Folder Name or File Name)
- [ ] Layout: display next to the seek bar (Time or Frame Number)
- [ ] Playback: combine Fast Forward and Rewind under "Skip" in the Playback menu
- [ ] Playback: combine Zoom and Pan controls under "Pan & Zoom" in the View menu
- [ ] Playback: when no video is selected, frame-by-frame and range selection shortcuts apply to all videos
- [ ] Playback: Repeat Synchronization — Off / Wait for longest / End with shortest
- [ ] Playback: frame-by-frame navigation with Alt + Mouse Wheel
- [ ] Playback: rename and move files even while they are playing
- [ ] Shortcuts: customize keyboard shortcuts in Shortcuts (F1)
- [ ] Settings: reorganize tabs — rename "Data" to "Capture", move Cache Folder to "General", add "Controls" tab
- [ ] Settings: close menus when the mouse moves away from them
- [ ] Languages: download additional languages from the update site — Japanese, Spanish, Simplified Chinese

### New Features

- [ ] Compare two videos — Mix or Wipe mode with slider (Free: 10 min/day)
- [ ] Transform (Right-click): rotate 90 degrees, flip horizontally/vertically, change aspect ratio
- [ ] Delayed Play (Right-click): start another video at the current frame; repeats until stopped (Free: 10 min/day)
- [ ] Free Crop (Right-click > Crop): crop to any shape using a single slider
- [ ] Capture: choose save method (Combined / Individual)
- [ ] Capture: options for parameters — Selection Frame, Zoom/Crop, Seek Bar, Name Label, Highlight Frame
- [ ] Help > Previous Session: show last session info (actions, screen, videos)
- [ ] Bug reports: attach video info (format, codec, resolution — no filenames); preview before sending
